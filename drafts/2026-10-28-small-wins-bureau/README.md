# The Bureau of Small Wins

**Date:** 28 October 2026  
**Status:** Draft, awaiting explicit review and approval. Not linked from the Studio homepage or daily journal.  
**Medium:** Interactive editorial certificate / A4 print design, built with HTML, CSS and plain JavaScript.

## Concept

A fictional government office treats everyday achievements with the ceremonial seriousness normally reserved for major awards. The joke lives in the contrast between a tiny personal victory and an oversized official certificate.

**Audience:** Adults who appreciate playful editorial design, witty typography and small rituals of celebration.

**Craft decisions:** Warm uncoated-paper colour, ink-red stamp, monospaced filing details, exaggerated serif hierarchy and fine print create a recognisable paper form. No stock imagery, AI-looking effects, third-party fonts, accounts or network calls. The document is deliberately print-first, with an A4 stylesheet and an accessible interactive form.

**Interactions:** Type up to 110 characters, select one of three stamps, issue the certificate, then print or save as PDF using the browser. Nothing is stored or transmitted. Empty submissions are rejected; printing is gated until a certificate is issued.
