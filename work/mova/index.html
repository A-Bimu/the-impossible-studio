01 / The problem

Why this
exists.

When delivery information is fragmented, every team loses time on status questions. Customers ask where a package is, while dispatch teams need to act on what happens next.

02 / The design response

Intentional
by design.

MOVA connects the booking, shipment list, tracking timeline and dispatch board into one visual language. A high-contrast industrial aesthetic makes state changes visible, while the details stay compact for faster scanning.

05 / Honest prototype notes

What is
really built.

MOVA uses fictional recipients and shipment routes. Maps are illustrations, not GPS or navigation. No parcels are collected or delivered, no tracking network is connected and no prices are charged. Data remains local to the browser.

This is independent speculative portfolio work, not a commissioned client project. All eight device previews display responsive states of the actual HTML and JavaScript demo. The interactions can be tested in a full-screen browser. The typographic brand board is original CSS-based presentation artwork; no photographic assets or completed videos are claimed.
