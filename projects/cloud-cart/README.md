# Cloud Cart · Good things float.

**Business model:** curated online grocery and essentials retailer. Customers purchase from Cloud Cart directly. It is neither a multi-seller marketplace nor only a delivery app.

**Status:** interactive landing-page concept with product categories, live search, local bag, and simulated checkout. All products, prices and order flows are sample data.
