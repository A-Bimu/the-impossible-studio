# Contribution workflow

1. Begin with a specific new concept and a separate folder.
2. Cross-check for unwanted repetitions against the studio archive.
3. Capture exactly which image, web prototype or motion file was approved.
4. Verify public-release safety: no private files, real customer details or credentials.
5. Publish source, original approved asset, and honest README status.
6. Use small, descriptive commits and update APPROVALS.md.
