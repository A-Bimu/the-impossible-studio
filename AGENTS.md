# The Impossible Studio: Creative Guidelines

- Work only on approved studio art and experimental design, never modify ALIA, KidyCode, Eureka, KOVU, or unrelated repositories.
- Refer to `creative-direction/CREATIVE_ART_DIRECTION.md` before creating or modifying artwork.
- Distinctive concepts and medium-specific visual craft come before gloss, clutter, and generic effects.
- No repetition of earlier motifs unless requested. Don't default to miniature worlds or glossy 3D.
- Preserve approved versions and label drafts clearly.
- Public repository: never publish credentials, private data, API keys, or unlicensed images.
- Do not claim media has been uploaded unless the actual GitHub file exists.
- Future chat approvals do not automatically trigger GitHub uploads without an active connected workflow.
