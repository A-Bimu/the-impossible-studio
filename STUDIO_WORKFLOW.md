# The Impossible Studio: publishing and stall protocol

This is an independent public creative gallery, separate from the professional portfolio.

## Approval and publication
- Add only the specific work the owner approves. Preserve approved originals and do not quietly replace them with remakes.
- Keep artwork, videos and code in the appropriate project folder, and update the gallery index with accurate categories and status.
- Mark drafts and unfinished animations as in progress; never call an image a completed video.
- No private credentials, customer data, NDA work or unlicensed third-party assets in the public repository.
- Verify the actual GitHub commit and deployed Vercel URL after each release. Preview images must not be confused with interactive projects.

## Stop-the-loop rule
- Stop after one repeated failure or after five minutes without meaningful forward progress.
- Identify the failing step and its cause; use one substantially different recovery technique.
- If that fails, stop, report what succeeded and what is blocked, and give the user one clear next action. Do not retry identical steps indefinitely.
- Do not claim files are uploaded merely because they exist in a local container or a chat attachment.
- During an active conversation, notify the user of a blocker immediately. Outside an active workflow, ChatGPT cannot independently watch tool activity and send a five-minute alert unless a separate monitoring automation is configured.
