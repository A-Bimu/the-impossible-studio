## Creative rule

Every project is concept-first, not a repeat of the last successful visual trick. No generic glossy AI look by default, no unapproved redesign of existing work, and no automatic publishing of drafts. See [our art-direction guide](./creative-direction/CREATIVE_ART_DIRECTION.md).

## What is approved and what is actually uploaded?

See [APPROVALS.md](./APPROVALS.md) for a precise status inventory. The approved artwork and video media that cannot be transferred automatically are listed as pending. **A reference or approval record is not a substitute for the original file.**

## Privacy and safety

This repository is **PUBLIC**. Never commit API keys, private customer details, unpublished contracts, confidential company files, or paid copyrighted reference images. This studio is separate from ALIA, KidyCode, Eureka, KOVU, and other independent projects. The fictionally branded demos do not charge customers.

## How new approved work is added

When you approve a design in chat, we identify the exact version and add its files or a verified source package on request during the same workflow. This GitHub repository cannot automatically read new chat approvals without a connected publishing workflow running at that time. If the binary upload step is unavailable, track it in [APPROVALS.md](./APPROVALS.md) rather than falsely marking it published.
