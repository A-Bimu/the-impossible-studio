# The Impossible Studio: daily design and publication rules

## Daily design practice
- Create one concept each day, with a fresh direction and no repetitive imagery or visual tricks.
- Ideas may be an interface, landing page, brand identity, campaign, moving image, poster, illustration, object or an unexpected combination.
- A daily concept should include its idea, the intended audience or purpose where relevant, its final visual/artifact, a short description of decisions, and a status: draft / in review / approved / published.
- The user reviews each concept. Only publish to the public studio if the user has approved that specific work.
- Never claim a video has been made when only stills exist. Never substitute imaginary descriptions for finished assets.

## Public studio structure
- The studio homepage is the independently shareable gallery. It holds category filters, featured work, and a link to the user's professional portfolio.
- Each finished major project has a scrollable case study: opening visual, project overview, creative decisions, gallery of the actual approved source images, a real video when available, and an interactive demo if available.
- Storefront demo checkouts are simulated; price tags are examples and clearly labeled accordingly.
- ZEBRA and Deep Ink remain preserved in their approved original forms. Withdrawn designs must not appear in public galleries, dated journals, or demo routes.

## Five-minute stop-the-loop rule
- Stop retrying the same blocked tool step after a repeated failure or five minutes without real progress.
- Identify the exact blocker, try one meaningfully different recovery method, and promptly tell the user if it still fails.
- Do not attempt endless uploads, downloads or deployments.
- Verify each published GitHub commit and production Vercel deployment. An unchecked URL is not a verified live result.
